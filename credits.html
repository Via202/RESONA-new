About & Credits

A browser-based audiovisual music experience.

01 / THE CONCEPT

Listen with your eyes.

RESONA is an experimental interactive website that transforms music listening into a creative audiovisual experience. Designed for music lovers and curious creators, it encourages users to explore, customize, and experiment with sound and visuals through an intuitive, playful interface.

Users can generate original procedural compositions in CREATE mode or transform built-in and uploaded tracks in REMIX mode. Through interactive controls, they can manipulate musical characteristics, sound effects, colors, and animations, discovering how changes in sound and visuals influence one another.

The experience features five distinctive environments: Underwater, Dreamcore, Space, Lo-fi Retro, and Digital Cyberpunk, each offering a different visual and musical atmosphere. Rather than simply listening to music, users become active participants in shaping their own audiovisual experience.

RESONA aims to make music experimentation accessible, immersive, and entertaining, without requiring prior knowledge of music production.

03 / VISUALS & ASSETS

Built from shape and light.

Liquid, Geometric, Soundwave and Dreamlike respond to the audio through procedural Canvas 2D visuals. Cyberpunk uses a procedural particle sculpture.

The interface uses Roboto Condensed from Google Fonts, with system sans-serif fallbacks. The project wordmark uses Gugi. HUD labels, control labels and canvas captions retain monospace typography.

04 / TECHNOLOGIES & TOOLS

Small tools. Open possibilities.

HTML, CSS, vanilla JavaScript modules, Canvas 2D and the Web Audio API.

Local development: VS Code Live Server or the included Node.js static server. Automated checks use Node’s built-in test runner. Prototype implementation assisted by OpenAI Codex.

Both CREATE and REMIX support WAV and 320 kbps MP3 export.

MP3 export uses the LAME MP3 Encoder via lamejs 1.2.1 under the GNU LGPL. Download the encoder source or read the notices and replacement instructions. The encoder source code, license notices and replacement instructions are available through the accompanying links.
